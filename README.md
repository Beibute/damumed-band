# Damumed Band

Аналитический отчёт по запуску браслета для контроля здоровья под брендом Damumed:
производство, клиническая модель, регистрация медизделия, рынок, приложение и экономика.

Сайт: https://beibute.github.io/damumed-band/

## Состав

| Файл | Что это |
|---|---|
| `index.html` | отчёт целиком: графики, схемы устройства, мокапы приложения, встроенный калькулятор |
| `calculator.html` | полноразмерный калькулятор экономики со всеми допущениями |
| `files/damumed-band-otchet.docx` | детальный отчёт в Word |
| `files/damumed-band-rezyume.docx` | инвестиционное резюме для совладельцев |
| `files/zapros-nnczrz.md` | готовый текст запроса в ННЦРЗ |

## Как обновлять

Исходники живут в основном рабочем репозитории, в `projects/damumed-band/`.
Сборка сайта — скриптом оттуда; сюда попадает готовый результат.

## Внимание

Страница закрыта от поисковых систем метатегом `noindex`, но сам сайт публичный:
адрес открывается без авторизации. Не размещать здесь данные, которые не должны
попасть к третьим лицам.
